## 🚀 Featured project

### Modbus Devices

A Home Assistant integration for industrial Modbus equipment.

The project brings real industrial devices into Home Assistant as native
entities and provides device-specific protocol handling, configuration
flows, and presentation.

**Highlights:**
- Available through the HACS default repository
- Support for industrial equipment from multiple manufacturers
- Modbus RTU, TCP and RTU over UDP
- Hardware-tested implementation
- Automated tests and Home Assistant validation
- HACS-compatible release workflow

➡️ See the pinned **Modbus_Devices** repository above.
